# dotfiles (. 📁)

- My i3wm dotfiles (Nord Theme)

## Packages & Dependencies :

 - This is the list of packages and dependencies to be installed :

```picom, starship, xautolock, xinput (to list your input devices that would be used for i3 config file) , rofi, polybar, zathura, ghostty, tmux, cava, btop, superfile, Nerd Fonts```
 
 - Links for Nerd Fonts:
     - https://github.com/ryanoasis/nerd-fonts/releases/download/v3.5.1/JetBrainsMono.zip
     - https://github.com/ryanoasis/nerd-fonts/releases/download/v3.5.1/FiraCode.zip
 - Link for Tmux Nord Theme: https://www.nordtheme.com/docs/ports/tmux/installation
